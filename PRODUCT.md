# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Static single-file HTML page built by `scripts/build.py` from `content/*.md`, rendered client-side (marked, highlight.js, mermaid) and published as a claude.ai Artifact. Constraints: scripts only from allow-listed CDNs, stylesheets only from Google Fonts, no external images or fetches, must render in light and dark themes and at phone width.

## Users

Working software engineers with some LLM application experience, studying in evenings and on weekends to move into AI engineering and AI system design roles. They read long lessons on a laptop (40 to 60 minutes per lesson), work through labs alongside, return over twelve weeks, and need to find their place quickly.

## Product Purpose

A free, independent course on designing production AI systems: agents, retrieval, evals, security, deployment, observability, and an enterprise track. It exists because comparable cohorts cost about $2,200. Success means learners finish the core six weeks, go as far into the enterprise six as their work needs, can answer the design review questions, and ship the capstone.

## Positioning

The only free course that covers the full production stack in one running project (Relay) with a tested reference implementation per lab, sourced and fact-checked numbers in every lesson, and security and operations depth that free alternatives lack.

## Content and features to preserve

36 pages (orientation, 6 weeks of lessons and labs, library pages), Mermaid diagrams, tables, code blocks with copy, five callout types (design rule, watch out, tip, back of the envelope, design review question), self-check quizzes, search, per-browser progress tracking, light/dark/system theme toggle, hash-based deep links per lesson.

## Brand

Name: "AI System Design". No logo. Independent course; must not imply affiliation with any paid cohort.
